Moeen / مُعين: judge mirror

A static mirror for the "Create AI Agents" judges. Moeen is a bounded AI agent loop: an AI solver drafts a fix and a test, deterministic checks verify it, and a pull request opens only after a named human approves the exact diff. Every step is recorded in a hash-chained ledger.
